# CMMC Launch Hub Pilot Pricing And Tiers

Date: 2026-06-05  
Status: Pilot package guidance, not billing implementation

## Important Note

CMMC Launch Hub does not currently implement billing. This document describes pilot tier positioning and access expectations for enrollment, sponsor conversations, and pilot support.

## Tier Overview

| Tier | Intended Use | Current Access Pattern |
| ---- | ---- | ---- |
| Sponsored | Sponsor-supported limited pilot access | Level 1-oriented access with sponsor limitations. |
| COMM_L1 | Commercial Level 1 readiness | Level 1 assessment, evidence, dashboard, Executive and SPRS reporting paths. |
| COMM_L2 | Commercial Level 2 readiness | Full implemented platform access, including advanced reports/tools. |

## Sponsored

Sponsored access is intended for sponsor-supported pilot participants that need limited onboarding and Level 1-oriented readiness exposure.

Implemented limitations include restricted access to advanced Level 2 tools and reports. Sponsored organizations should be guided closely so expectations are clear.

Typical fit:

- Early discovery.
- Sponsor-supported readiness introduction.
- Organizations not yet ready for full commercial workflow.

## COMM_L1

COMM_L1 is intended for organizations focused on Level 1 readiness and initial evidence/reporting discipline.

Expected access:

- Organization Dashboard.
- Company Profile.
- User and invitation workflows for OrgAdmins.
- Level 1 assessment workflows.
- Evidence and OCR workflows.
- Executive Readiness Report.
- SPRS Scorecard.
- Activity Center for OrgAdmin/OrgOwner.

Restrictions:

- No Level 2 assessment functionality.
- No advanced Level 2 reporting shortcuts.
- No SSP PDF export shortcut.
- No Responsibility Matrix shortcut.
- No POA&M workspace shortcut when treated as Level 2-only.

## COMM_L2

COMM_L2 is intended for organizations preparing for Level 2 readiness workflows.

Expected access:

- COMM_L1 capabilities.
- Level 2 assessment access.
- POA&M workspace.
- SSP PDF export.
- Responsibility Matrix.
- Advanced reporting/tooling currently implemented.

## User Limits

Pilot organizations should confirm expected users before onboarding. Current invitation and seat checks are implemented in the application path, including pending invitation handling.

## Pilot Pricing Guidance

Because billing is not implemented, pilot pricing should be handled outside the application. Recommended pilot options:

- Sponsored pilot seat: sponsor-funded, limited cohort, guided support.
- COMM_L1 pilot: fixed pilot fee or no-cost evaluation with defined duration.
- COMM_L2 pilot: higher-touch pilot access for organizations needing Level 2 workflows.

Pricing should be finalized only after pilot feedback confirms packaging, support effort, and value.

## Upgrade Considerations

Organizations may request tier upgrades when Level 2 workflows are needed. SuperAdmin and support teams should confirm the organization, need, and intended scope before adjusting tier.

## Not Included

- In-app billing.
- Automated invoicing.
- Payment processing.
- Email notifications.
- Usage-based AI billing.
